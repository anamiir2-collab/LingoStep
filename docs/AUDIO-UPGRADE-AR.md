# ترقية نظام الصوت — LingoStep (Section 20)

ترقية كاملة لنظام الصوت في التطبيق الأصلي **دون المساس بأي درس أو محتوى**. كل الملفات الجديدة تُضاف بجانب التطبيق، وثلاثة ملفات فقط يتم تحديثها بطريقة آمنة ومُتحقَّق منها (`js/speech.js` و`js/app.js` و`sw.js`).

---

## ✨ ماذا يضيف هذا التحديث؟

| الميزة | التفاصيل |
| --- | --- |
| **لهجة أمريكية / بريطانية** | اختيار US أو UK أو «تلقائي»، مع زر معاينة لكل صوت |
| **اختيار الصوت** | قائمة بالأصوات الموجودة فعلًا على جهازك، مع وسوم صادقة: «طبيعي» / «بدون إنترنت» / «أونلاين» |
| **سرعة النطق** | بطيء / عادي / سريع — بدون أي تشويه في حدة الصوت (Pitch ثابت) |
| **مستوى الصوت** | متحكم بحجم الصوت مع تجربة فورية |
| **تكرار تلقائي** | إعادة الجملة 1× / 2× / 3× تلقائيًا |
| **أزرار التشغيل** | إيقاف مؤقت / متابعة / إعادة آخر جملة / إيقاف |
| **تدريب المحادثة (تجريبي)** | استمع ثم أعد الكلام (وضع الظل) + تسجيل صوتك ومقارنته + التعرف على الكلام (اختياري) |
| **أمان النطق** | لا تُقرأ أبدًا الرموز أو الإيموجي أو الترجمة العربية — الإنجليزي فقط |
| **صدق كامل** | كل الأصوات من جهازك (صناعية) — لا شيء يُقدَّم وكأنه تسجيل بشري |

الإعدادات تُحفظ على جهازك (localStorage) وتُستعاد تلقائيًا، وفيه زر «استعادة الافتراضيات».

## 📤 خطوات التركيب (3 دقائق)

> **قبل البدء:** افتح مستودع `LingoStep11` على GitHub واحذف أي ملف ZIP قديم من جذر المستودع (مثل `LingoStep11 (1).zip`) — حتى لا يعاد فك ضغطه بالخطأ.

### 1) ارفع ملف ZIP الجديد
- من صفحة المستودع: **Add file → Upload files**
- ارفع الملف باسم `LingoStep11-updated.zip` **كما هو بدون فك الضغط** ثم **Commit changes**

### 2) شغّل استخراج الملفات الجديدة
- تبويب **Actions** → اختر **"Extract LingoStep11 ZIP into repository"** → **Run workflow** → انتظر حتى ينجح ✓
- هذه الخطوة تضيف الملفات الجديدة فقط ولا تمس أي ملف موجود.

### 3) طبّق الترقية
- تبويب **Actions** → اختر **"Apply Audio Upgrade (Section 20)"** → **Run workflow** → انتظر حتى ينجح ✓
- هذه الخطوة تحدّث الملفات الثلاثة وتحذف ملفات ZIP من المستودع تلقائيًا.

### 4) افتح الموقع
- `https://anamiir2-collab.github.io/LingoStep11/`
- **حدّث الصفحة مرتين** (تحديث عادي ثم ثانية) حتى يتفعّل Service Worker الجديد.
- افتح: **More → Speech** — ستجد اللوحة الجديدة كاملة.

---

## 🧪 قائمة فحص سريعة بعد التركيب

1. More → Speech → جرّب زر **تجربة** مع كل لهجة (US / UK).
2. غيّر **السرعة** إلى «بطيء» وشغّل أي درس — يجب أن يكون أبطأ بنفس حدة الصوت.
3. خفّض **مستوى الصوت** واضغط تجربة.
4. اضبط **تكرار تلقائي** على 2× وشغّل جملة — تتكرر مرتين.
5. جرّب **إيقاف مؤقت / متابعة / إعادة / إيقاف**.
6. افتح **تدريب المحادثة**: استمع → سجّل → شغّل تسجيلك → احذف.
7. انتقل لدرس ثم اخرج — **يجب ألا يستمر الصوت** بعد تغيير الشاشة.
8. جرّب الموقع بدون إنترنت — يعمل كالمعتاد (الأصوات حسب جهازك).

## 🔙 التراجع (إن احتجت)

- تبويب **Commits** → ابحث عن كوميت *"Apply Section 20 audio upgrade"* → **Revert** → Push.
- أو من محلي: `git revert <commit-hash> && git push`.
- التراجع يعيد التطبيق كما كان تمامًا — الملفات الجديدة تظل لكنها غير مفعّلة.

## 📝 ملاحظات فنية

- الصوت لا يزال 100% من الجهاز (Web Speech API) — بلا خوادم وبلا مفاتيح.
- جودة ونطق الأصوات يختلف حسب الجهاز والمتصفح؛ كروم/إيدج يوفران أفضل الأصوات عادةً.
- التعرف على الكلام متاح فقط في المتصفحات الداعمة (كروم/إيدج) وقد يخطئ — النتيجة تلميح وليست تقييمًا للنطق.
- سجل الاختبار الكامل موجود في `docs/AUDIO_REPORT.md` داخل المستودع.
