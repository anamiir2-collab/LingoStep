# LingoStep11

LingoStep is a complete English learning app for Arabic speakers: structured lessons organized by level, interactive exercises of all kinds, clear Arabic explanations for every word and sentence, listening and pronunciation practice with real everyday phrases, progress tracking, and a modern mobile-first design for phones, tablets and desktop.

**v8.0.0 — keyboard-free mobile transformation:** every exercise is answered by touch (tap cards, word chips, letter tiles, or the built-in letter keyboard — no system keyboard ever appears during lessons). Installable PWA, offline support, achievements, streaks, XP and full Arabic/English support. See `docs/MOBILE_APP_GUIDE.md` for deployment and Android/iOS packaging (Capacitor).

- 252 lessons across 11 sections (A1 → C1), 14,000+ practice sentences
- 100 % keyboard-free answering — preserving the original questions, answers and scoring
- Progress, streaks and XP stored locally (IndexedDB) with backup/restore
- Run locally: `npm start` · Tests: `npm test` · Content validation: `npm run validate:lessons`
